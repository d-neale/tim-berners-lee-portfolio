# Tim Berners-Lee Portfolio (Concept)



A small concept portfolio site celebrating Sir Tim Berners-Lee and the creation of the World Wide Web. Built primarily with HTML and CSS, with a small vanilla JavaScript snippet used on the timeline page for smoother navigation and consistent card sizing.



**Live site:** https://d-neale.github.io/tim-berners-lee-portfolio/
